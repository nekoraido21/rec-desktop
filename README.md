# REC デスクトップ版 ダウンロード

配信の「まわり」を自動にする、無料の配信サポートアプリ **REC** の配布用ページです。
（ソースコードはここにはありません）

- 公式サイト：https://rec.nekoraido.workers.dev
- ダウンロード：[最新版（Releases）](https://github.com/nekoraido21/rec-desktop/releases/latest)

## どれをダウンロードする？

| パソコン | ファイル |
|---|---|
| Mac（M1 / M2 / M3 / M4 など Apple シリコン） | `REC-x.x.x-mac-arm64.dmg` |
| Mac（Intel） | `REC-x.x.x-mac-x64.dmg` |
| Windows | `REC-x.x.x-win-x64.exe` |

## はじめて開くとき

REC はまだ開発元の署名（有料の証明書）をしていないため、はじめて開くときに警告が出ます。

- **Mac**：「開発元を確認できない」と出たら、アプリを右クリック →「開く」。開けないときは「システム設定」→「プライバシーとセキュリティ」の下にある「このまま開く」を押してください
- **Windows**：「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押してください
